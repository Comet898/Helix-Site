Your own Wisp server (public ones go offline a lot).

Local:   npm install && npm start   ->  ws://localhost:8080/
Render:  push this folder to a GitHub repo, then New > Blueprint on render.com (render.yaml is included). Your address will be wss://NAME.onrender.com/
Others:  Dockerfile included (Fly.io, Railway, Koyeb ...).

Then paste the wss:// address into Settings > Preferred Wisp server.
